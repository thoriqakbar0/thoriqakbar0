# Thoriq Akbar

I build AI products at [Pandai](https://pandai.org), where I lead engineering for AskPbot, MathDrill, and P&AI. I also build tools for working with agents and write about the work at [ta-0.com](https://ta-0.com).

## Projects

- **[WSM](https://wsm.ta-0.com)** — A Python SDK for experimenting with model weights, comparing results, and saving checkpoints.
- **[P&AI](https://github.com/p-n-ai/pai-bot)** — An open-source tutor that starts curriculum-based practice over chat, tracks mastery, and schedules review.
- **[Ernie](https://ernie.ta-0.com)** — An alpha desktop app for Prime Agent that explores how agents can help shape the interface people use to work with them.
- **[gateway](https://gateway.ta-0.com)** — One API key for accessing models from multiple providers and calling tools from the same prepaid balance.
- **[browser.jr](https://browserjr.ta-0.com)** — An early browser engine experiment built around what agents need from a browser.
- **[Garden](https://garden.ta-0.com)** — An independent Go runtime for hosting Eve-compatible agents on your own infrastructure.
- **[Agent Lite](https://github.com/thoriqakbar0/agent-lite)** — A fork of `agent-browser` that brings its CLI workflow to Firefox through Camofox.
- **[Skills](https://github.com/thoriqakbar0/skills)** — Reusable instructions for the workflows I run with coding agents.
- **[Monkey](https://github.com/thoriqakbar0/monkey)** — One shell command for creating and switching between Git worktrees.
- **[Ship LLM](https://github.com/thoriqakbar0/ship-llm)** — A Python library that makes calling an LLM feel like calling a function. Archived.
